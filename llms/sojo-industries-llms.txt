# Sojo Industries

> Sojo Industries is a national industrial-automation and supply-chain technology company
> (founded 2021, Bristol, Pennsylvania) serving the food and beverage industry with robotics-driven
> variety packing, multi-packing and assembly. Its API surface consists of the Sojo Shield
> track-and-trace platform API and a production Model Context Protocol server for "Victoria",
> the SOJO Planning Assistant.

## Agent surfaces

- [MCP server — SOJO Planning Assistant](https://victoria-agent.sojoshield.com/mcp): Streamable-HTTP
  Model Context Protocol endpoint, protocol version 2025-06-18, server version 3.4.5. `initialize`
  and `tools/list` succeed ANONYMOUSLY — no token needed to read the full tool contract. Send
  `Accept: application/json, text/event-stream` or you get a 406. Six tools: `query_database`
  (RAG-backed production/machine questions), `list_tables`, `describe_table`, `get_table_sample`,
  `analyze_dieline` (carton geometry vs a target packaging line), `analyze_pallet_pattern`
  (palletiser compatibility). All six are read-only.
- [OpenAPI 3.0.3 — Victoria Planning Assistant API](https://victoria-agent.sojoshield.com/openapi.json):
  8 paths, 10 operations, HTTP 200 anonymous. Covers `/orchestrate`, SSE `/api/chat`, conversation
  list/get/rename/delete/export, `/upload-image`, `/health`, `/ready`.
- No A2A agent card. `/.well-known/agent-card.json` and `/.well-known/agent.json` return 404 on
  victoria-agent.sojoshield.com and www.sojoindustries.com, and an HTML SPA shell (not a document)
  on sojoshield.com.

## APIs

- [Sojo Shield Platform API](https://api.sojoshield.com/docs): base
  `https://api.sojoshield.com/api/v3/`. Public Swagger UI titled "Shield API". Every data path
  returns HTTP 401 `{"data":{"message":"No bearer token provided."},"error":{"code":"UNAUTHORIZED"}}`.
  KNOWN DEFECT as of 2026-08-28: the spec the Swagger UI loads,
  https://api.sojoshield.com/swagger.json, returns HTTP 503 `{"error": "Swagger spec not initialised"}`,
  so no machine-readable Shield contract can be retrieved by anyone.
- [Victoria / SOJO Planning Assistant API](https://victoria-agent.sojoshield.com): see above.

## Authentication

- Bearer JWT only. The credential is a Stytch session JWT, resolved to a Shield identity server-side.
- No OAuth authorization-server metadata, no OpenID Connect discovery, no API keys, no documented
  scopes, no self-service sign-up. Access requires a Sojo Shield customer account.

## Conventions

- Errors: custom envelope `{"data":{"message":...},"error":{"code":"UPPER_SNAKE","details":{}}}`.
  Not RFC 9457.
- Pagination: `page` + `limit` query parameters on `GET /api/chat/conversations`.
- Idempotency: none. No idempotency key or header on any write.
- Rate limits: none published, and no `X-RateLimit-*`, `RateLimit-*` or `Retry-After` header is
  returned on any response.
- Versioning: Shield versions in the path (`/api/v3/`); the Victoria contract's `info.version` is
  the environment label `langgraph-production`, not a version.
- Reversibility: `DELETE /api/chat/conversation/{session_id}` is a soft delete, but no restore
  operation and no retention window are published. Treat writes as irreversible.

## Products

- Sojo Hubs — regional automated packaging facilities (Pennsylvania, New Jersey, California, Texas).
- Sojo Flight — mobile manufacturing lines trucked to a customer's own plant.
- Sojo Shield — blockchain-backed track-and-trace platform; an Oracle "Built for NetSuite" SuiteApp;

  not declared in any retrievable contract.
